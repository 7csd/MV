逐镜制作，再合成整支 MV

方案与分镜

上传音乐和歌词，选择人物与风格，生成整片方案。故事、分镜说明与展开的动作安排均可编辑并保存，镜头图片可单独生成或上传。

动态样片

在分镜卡片生成单镜样片，或勾选部分镜头生成，也可一键生成全部。每个镜头可预览、提出修改并重新生成；修改意见明确保存镜头编号和名称。观看后逐镜确认。

合成与交付

所有镜头当前版本通过后，点击页面下方“生成全片 MV”，统一剪辑原曲、歌词与转场。连续观看整片，满意后确认导出1080p；需要调整时选择对应镜头重做、确认并重新合成。

测试阶段由模型读取平台任务代执行并回传；接入 API 后由平台自动执行同一份任务。两种方式共用生成、预览和确认流程。
