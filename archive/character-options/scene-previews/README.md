# 人物放入原 MV 场景的静帧效果预览

本轮采用 C 组“精致剪纸”男女主，以原视频中的三张截图作为合成参考，生成独立静帧概念图：

1. 开场纸山：女主站在金色纸路上，三分之二以上正面朝向镜头，双眼可见。
2. 双人相遇：男女主在落叶和人海中牵手，共同拿住星片。
3. 黎明纸花：女主正面站在层叠纸花前。

仅用于判断新人物与背景的视觉协调性；不是从动画工程重新渲染的人物替换帧，也不是对原背景逐像素锁定的合成结果。生成过程会有少量比例、姿态、服饰和背景细节差异。当前视频、原始截图和 Remotion 工程均未修改。

使用内置 image_gen 编辑工具，每张图以对应视频截图为编辑目标，以 C 组人物设定图为身份与纸张风格参考。完整提示词保存于 prompts.json。
